# 管理员使用手册

本文是草稿示例，用来演示草稿箱功能。登录管理页后可以看到它的状态是「草稿」，只有登录后才能预览，不会出现在首页。

## 写作方式

编辑文章支持两种模式，可以随时切换：

- Markdown 模式：左边写，右边实时预览；
- 可视化模式：所见即所得，工具栏支持加粗、标题、列表、引用、链接、代码块等。

## 图片

在编辑器中可以这样加入图片：

- 点击可视化工具栏的「图片」按钮上传本地图片；
- 直接粘贴截图（Ctrl + V）；
- 把图片拖进编辑区域。

图片会自动压缩，并保存到博客仓库的 images 目录，文章中以相对路径引用，发布后即可在网页上查看。

## 发布流程

1. 写完后点「保存草稿」或「发布」；
2. 已发布的文章会立即出现在首页；
3. 草稿留在管理页，随时可以继续编辑。

## 评论与统计

在「站点设置」里可以开启 Giscus 评论（需要仓库开启 Discussions），以及可选的访问统计。

## 代码块示例

```python
def greet(name):
    """一个简单的问候函数"""
    print(f"你好，{name}")
    return True

greet("博客")
```
