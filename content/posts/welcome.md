# 你好，我的博客

欢迎来到我的博客。

这里是我随手记录的地方：学习笔记、技术教程、生活随笔，都会陆续出现在这里。

## 这个站点怎么用

- 首页按时间列出已发布的文章，可以用顶部的分类快速筛选；
- 按 `Ctrl + K` 或 `/` 可以随时搜索站内文章；
- 文章里的代码块右上角有复制按钮；
- 点击文章里的图片可以放大查看。

## 如何写第一篇文章

点击右上角的「管理」进入管理页，按提示完成首次设置（填入 GitHub 仓库地址和访问令牌，设置管理员密码）。

之后就可以新建文章、上传图片、保存草稿或直接发布。发布的内容会同步到仓库，任何设备打开博客都能看到。

祝你写得开心。
